LearnForgeX is an independent learning platform created by Cemalettin Durgun. It offers free lessons for people who want to learn software development.

## What's here?

The platform currently has 7 courses and more than 160 lessons:

- [Java](/en/courses/java)
- [Spring Boot](/en/courses/spring-boot)
- [React](/en/courses/react)
- [Artificial Intelligence](/en/courses/ai)
- [PostgreSQL](/en/courses/postgresql)
- [Git & GitHub](/en/courses/git-github)
- [Docker](/en/courses/docker)

Lessons are published in Turkish and English. You don't need an account to read the lessons or download them as PDFs. The quizzes in the Java course are open to everyone; the quizzes and practice sections of the other courses require a free account.

## Approach

The lessons aim to do more than define a technology: they show when and how it can be used in real software development. That is why every lesson explains its topic with code examples, and most lessons end with a quiz that tests what you have learned.

When you finish a lesson, the goal is that you can answer not only "What is this?" but also "When and how would I use it?"

## Behind the platform

Cemalettin Durgun is a software developer with professional experience in software development, particularly in Java and backend development. The lessons on LearnForgeX draw on that experience to explain the concepts that come up in real projects, in a structured order.

The platform is still growing: new lessons are added, and existing lessons are updated when needed.
